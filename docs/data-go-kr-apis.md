# 공공데이터포털(data.go.kr) API 목록

작성일: 2026-10-17

## 키는 하나만 쓴다
- 아래 API는 모두 공공데이터포털에서 **활용신청**을 해야 쓸 수 있다.
- 인증키는 계정에 하나뿐이라 새 키를 받을 필요가 없다. 이미 `.env`의 `TOUR_API_KEY`, `KMA_API_KEY`에 같은 값이 들어 있다.
- 활용신청을 하지 않은 API는 키가 있어도 오류가 난다. API마다 하루 호출 한도도 따로 적용된다.

## 목록

| 기능 | 검색어 | 제공 기관 | 언제 신청하나 | 신청 상태 |

## 신청할 때 참고
1. https://www.data.go.kr 에 로그인한다.
2. 검색어를 입력하고, 제공 기관이 표와 같은 **OpenAPI**를 연다. 지자체별 데이터가 아니라 제목에 "전국"이 들어간 것을 고른다.
3. [활용신청]을 눌러 활용 목적을 적는다. 승인되면 같은 키로 바로 쓴다.
4. 행정안전부 표준데이터 두 개는 OpenAPI 없이 파일(CSV)로만 제공될 수 있다. 신청 전에 페이지에서 확인한다.
5. 신청하면 이 표의 "신청 상태"를 "완료"로 고친다.
